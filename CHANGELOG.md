# Changelog

## [2.2.0] - 2025-11-14

### Added
- Support for GNOME Shell 49

### Fixed
- Fixed workspace switching behavior when in Overview mode
  - Custom focus management is now skipped when Overview is visible
  - Prevents interference with GNOME's default Overview workspace switching
  
### Changed
- Updated shell-version in metadata.json to include version 49

## [2.1.0] - Previous Release
- Initial multi-monitor Alt+Tab support
- Workspace focus protection
- Configurable monitor detection (mouse vs focused window)
